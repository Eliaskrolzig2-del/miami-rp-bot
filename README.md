# Notruf Hamburg GeoGuessr Discord Bot

Ein einfacher Discord-Bot für das Notruf-Hamburg-GeoGuessr-Spiel.

## Features
- `!start` startet eine neue Runde
- `!guess <Ort>` rät den aktuellen Ort
- `!punkte` zeigt deine Punkte an
- `!rangliste` zeigt die Top-Spieler

## Installation

1. `cd Bot`
2. `npm install`
3. Kopiere `.env.example` nach `.env` und setze `DISCORD_TOKEN`
4. Erstelle einen Discord-Bot und aktiviere die benötigten Berechtigungen
5. `npm start`

## Daten anpassen

Die Orte werden in `data/locations.json` verwaltet. Du kannst dort echte Notruf Hamburg-Bilder und weitere Einträge hinzufügen.
